📋 Mudanças detalhadas

Bloco G — Multi-tenant + LGPD (Sprint 4 puxado pra frente)

  1. core/tenant.py — namespace por env var: bash LEMMON_TENANT_ID=hator # default: "default" tenant_namespace(HISTORICO_DIR, "dashboard") retorna historico/hator/dashboard/. Cada cliente tem seu próprio histórico isolado. Sem DB, sem migration.

  2. Cripto-at-rest com Fernet: bash # Gera chave nova: python -c "from core.tenant import gerar_chave; print(gerar_chave())" # Exporta: export LEMMON_ENCRYPT_KEY="gAAAAA..." cifrar_texto("briefing secreto") → "ENC:gAAAAA...". Sem chave, degrade graceful (retorna plaintext + warning). Lazy import do cryptography — não derruba sistema se não instalado.

  3. Audit log JSONL — core/audit.py: python from core import audit audit.registrar("brand_kit_atualizado", user="pedro", campos=["paleta_primaria"]) Grava historico/<tenant>/audit.jsonl (append-only). Desliga com LEMMON_AUDIT_DISABLE=1. Best-effort: nunca lança, mesmo com disco cheio.

  4. 3 endpoints LGPD (api/routes/lgpd.py):

  5. GET /lgpd/exportar → ZIP com todos os dados do tenant (sessões + brand kit + usuários + audit) com Content-Disposition: attachment.
  6. POST /lgpd/deletar-sessao body {session_id} → apaga sessão específica + arquivos relacionados.

  7. POST /lgpd/apagar-tudo → wipe completo do tenant. Exige LEMMON_AUTH_TOKEN (403 sem ele).

  8. Brand Kit (api/routes/brand_kit.py):

  9. GET /brand-kit → kit atual ou default ("Cliente", paleta verde Lemmon).
  10. PUT /brand-kit body com nome, tom_voz, paleta_primaria (#hex), paleta_secundaria, fonte_titulo, fonte_corpo, logo_url, instagram_handle, publico_alvo, palavras_evitar[], palavras_preferir[].

  11. DELETE /brand-kit → reset pra default. Storage: historico/<tenant>/brand_kit.json.

  12. Multi-user com permissões (api/routes/usuarios.py):

  13. GET /usuarios → lista users do tenant (token mascarado, ex: abcd1234...).
  14. POST /usuarios body {email, nome, role} (role: admin | editor | viewer) → cria + retorna token_inicial (32-char hex) UMA VEZ.

  15. DELETE /usuarios/{email} → remove user. Storage: historico/<tenant>/usuarios.json. Token mascarado nunca exposto após criação.

  16. Pedro Espelho que treina (api/routes/treino_pedro.py):

  17. POST /pedro/treinar → lê calibragem_pedro.json, filtra nota_acerto ≤ 3, manda pro Haiku consolidar em "## Aprendizados de calibragem", grava prompts/pedro_abrahao_system_v{N+1}.md. Exige LEMMON_AUTH_TOKEN em prod (ou LEMMON_ALLOW_TRAIN_DEV=1 em dev).

  18. GET /pedro/versoes → lista versões existentes do prompt (v1, v2, ...) com tamanho e data. Loop fechado: Pedro real corrige → calibragem registra → treino consolida → próxima versão do espelho IA fica melhor.

  19. PWA manifest — dashboard/public/manifest.json + dashboard/app/layout.tsx: json { "name": "Lemmon Agentes", "short_name": "Lemmon", "theme_color": "#10b981", "display": "standalone", "orientation": "portrait" } Pedro abre no iPad → "Compartilhar > Add to Home Screen" → ícone Lemmon na tela inicial. Funciona offline-first (cache do Next.js).

Bloco H — Segurança (8 itens)

  1. V-06 Next.js bump — dashboard/package.json 14.2.5 → 14.2.32. Fecha:
  2. CVE-2025-29927 — Authorization Bypass via middleware (crítico)

  3. 5 outras CVEs altas/médias de race condition + SSRF + DoS.

  4. V-12 Prompt injection unicode evasion — _normalizar_unicode() em concierge.py:

  5. NFKC normalization (compatibilidade canônica)
  6. Strip zero-width chars (U+200B, U+200C, U+200D, U+FEFF)

  7. Detecta i​g​n​o​r​e previous instructions mesmo com chars invisíveis.

  8. V-12b Role injection — heurística count("\n\n[") > 2 detecta múltiplas tags [system: ...] empilhadas (forma comum de jailbreak).

  9. V-16 Token calibragem 24→128 bits — secrets.token_hex(6) → token_hex(16). Era 24 bits (brute force trivial), agora 32 chars hex = 128 bits.

  10. V-25/V-26 Magic bytes em ws_chat._validar_magic_bytes:

  11. JPEG: \xff\xd8\xff
  12. PNG: \x89PNG
  13. GIF: GIF87a / GIF89a

  14. WebP: RIFF....WEBP Bypassa o MIME mentido pelo cliente (era confiar em image_mime_type).

  15. V-25b Image size em Pydantic — HistoricoMensagem.model_post_init rejeita image_base64 > 6.7MB (=5MB binário). Antes só o WS validava — modelo agora também.

  16. A-15b Calibragem race condition — _file_lock + tmp file + os.replace atomic. Antes era read→modify→write sem lock, 2 calls concorrentes perdiam um registro.

  17. D-3 PII no path — nome_projeto agora passa por regex sub CPF/email/telefone → [cpf]/[email]/[fone] ANTES de truncar pra nome de pasta. Antes vazava em outputs/.

curl http://localhost:8000/pedro/versoes

⚙️ Variáveis de ambiente novas

Env Default Descrição
LEMMON_TENANT_ID default Particiona histórico em historico/<tenant>/
LEMMON_ENCRYPT_KEY (vazio) Fernet base64. Sem ela, cripto degrade silencioso
LEMMON_AUTH_TOKEN (vazio) Bearer obrigatório em rotas sensíveis (LGPD apagar-tudo, treino Pedro)
LEMMON_ALLOW_TRAIN_DEV 0 Em dev, =1 libera /pedro/treinar sem auth
LEMMON_AUDIT_DISABLE 0 =1 desliga audit log (best-effort default = ON)
LEMMON_CORS_ORIGINS localhost:3000,4000 CSV de origens permitidas (CORS + WS origin check)
LEMMON_RATE_LIMIT_PER_MIN 60 Rate limit em memória por IP
